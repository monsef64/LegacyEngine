# Importing static 3D models

Use **Assets > Import files** (the Import button) and choose **3D Models
(all Assimp formats)** in the file picker. The filter is generated from the enabled importers
in bundled **Assimp 5.4.3**, rather than a hard-coded subset. Separate filters also offer glTF/GLB, FBX, OBJ,
Collada, Blender and STL/PLY choices. The full filter includes common
formats such as OBJ, FBX, glTF/GLB, Collada DAE, Blender BLEND, 3DS, STL and PLY,
plus the other formats supported by that build. Support for a format does not
guarantee support for every version, extension, or encoding of it. You can also
drop a model file onto Assets. Import can take time for large files.

## What gets imported

- Static triangle geometry, normals, and the first UV channel.
- Node transforms baked into the vertices; multiple meshes combined into one.
- Missing normals generated by Assimp. Point/line-only sources are rejected.
- At most 500,000 triangles and source files up to 256 MiB. Invalid/oversized
  coordinates or failed source imports display an Assets error.

Animated sources import **static geometry only**; there is no skeletal animation,
skinning, animation controller or morph playback in this implementation. Source
hierarchy, separate submeshes, vertex colors, source materials, textures, lights,
cameras and source collision meshes are not converted. Assign an engine material
in MeshRenderer afterward. Models start white, and existing backface culling
remains unchanged. Units and orientation follow Assimp's conversion; adjust the
object Transform as needed.

## Project-local asset and placement

Import produces a `.lemesh` baked geometry asset in the current Assets folder,
using a numbered filename if necessary. The original source is not copied or
modified. External files such as a glTF `.bin` must be accessible beside the
source **during import**; after baking, they are not needed to reopen the project.
Imported textures are not copied, since material conversion is not implemented.

Double-click the `.lemesh` asset, use its **Instantiate in level** context action,
or drag it into Scene to create an object at the Scene camera's target. A static
box Collider matching the model bounds is added for selection and basic collision;
it is **not** a triangle-mesh collider. Adjust/remove it as appropriate. No
RigidBody is added automatically.

Existing MeshRenderer components also have a **Model asset** picker/drop target.
Choosing a built-in Mesh clears its model reference. The model asset can be
shared by many objects and is uploaded to the GPU once per project session.
Failed loads are reported in the terminal; reopen the project after repairing a
missing/corrupt asset. Editing imported geometry externally requires reimport.

Scene, prefab and level data store the asset path, not GPU IDs or source paths.
Project Save As copies the baked asset with Assets. JSON scene format 12 and
legacy text format 17 add MeshRenderer.model while retaining old scene loading.
