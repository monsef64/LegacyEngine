# Generated terrain grass samples

Five AI-generated grass cutouts: meadow, dry, fescue, wild and short.
Processed into 512 x 512 RGBA PNGs with transparent backgrounds for terrain
crossed-card grass. These are generated test assets, not photographs.

In Terrain tools > Grass, click **Install 5 sample grass textures** to copy the
images into the current project's Terrain/Grass folder and add prototypes.
No existing project textures are overwritten. Check alpha edges, lighting and
scale manually in your scene before using them in a release.
